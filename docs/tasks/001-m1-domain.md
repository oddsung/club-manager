# TASK-001 — M1 도메인 로직: 회원 · 실력 등급 · 팀 자동 편성

> 상태: 완료

> 이 파일 내용을 그대로 Claude Code 세션에 붙여 넣어 시작합니다.

## 목표
`docs/requirements.md`의 **M1 범위(R-01, R-02, R-03)** 를 순수 TypeScript 도메인 로직으로 구현한다.

## 완료 조건 (모두 충족해야 완료)
1. `npm run check` 통과 (guards, lint, typecheck, test)
2. R-01~R-03의 각 규칙마다 최소 1개 이상의 테스트가 있다
3. 팀 편성 테스트에 다음이 포함된다
   - 같은 시드 → 같은 결과 / 다른 시드 → 다른 결과가 나올 수 있음
   - 인원 부족 시 오류, 인원 초과 시 대기 목록 반환
   - 비활성 회원 제외
   - 균형 검증: 무작위 입력을 여러 번 돌려 팀 간 등급 합계 최대 차이가 합리적 범위 이내임을 확인 (기준값은 근거와 함께 테스트에 명시)
   - 종목별 인원 예시(2, 4, 6, 11명 팀) 각각 동작
4. `/verify` 스킬의 보고 형식으로 결과를 보고한다

## 보고에 포함할 증거
- `npm run check` 출력 마지막 부분
- 사용한 팀 편성 알고리즘 한 줄 설명과, 균형 기준값을 그렇게 정한 이유

## 제약
- 범위는 M1만. UI, DB, 네트워크, 인증, 출석·회비 등 다른 기능은 만들지 않는다
- 외부 런타임 의존성을 추가하지 않는다 (필요하다고 판단되면 구현 전에 이유와 함께 질문)
- `Math.random` 직접 사용 금지 (lint가 막음) — 시드 주입 가능한 RNG를 직접 구현
- 요구사항이 모호한 부분은 추측하지 말고 `docs/requirements.md`의 "논의 중"에 질문으로 추가한 뒤 보고에서 알린다
- 작업 브랜치: `agent/m1-domain`, 완료 후 PR 생성 (push와 PR은 승인 요청)
