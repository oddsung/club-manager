# TASK-004 — 2단계 재검증: "휴대폰만으로" 병렬 사이클

> 상태: 완료

> 이 파일 내용을 그대로 Claude Code 세션(리드)에 붙여 넣어 시작합니다.

## 이번 사이클의 목적 (환경 검증)
TASK-003에서 팀원의 승인 요청이 휴대폰에 전달되지 않아 작업이 멈췄습니다.
권한 설정과 `AGENTS.md` 명령 형식 규칙을 보완했으니, 이번에는 **사람이 PC 앞에 한 번도 가지 않고 휴대폰만으로**
병렬 사이클이 끝나는지 확인합니다. 작업 내용은 일부러 작고 독립적으로 잡았습니다.

## 당신의 역할
당신은 **코디네이터(리드)** 입니다. `AGENTS.md` "팀 작업" 규칙을 따르고, 직접 코드를 쓰지 않습니다.

## 작업 내용
M2 모듈 3개에 대해 **경계값·예외 테스트를 보강**합니다. 팀원 1명이 모듈 1개를 맡습니다.

| 팀원 | 대상 | 만들 파일 (이 파일만) |
|---|---|---|
| `edge-attendance` | `src/attendance.ts` (R-04) | `tests/attendance.edge.test.ts` |
| `edge-dues` | `src/dues.ts` (R-05) | `tests/dues.edge.test.ts` |
| `edge-meetings` | `src/meetings.ts` (R-06) | `tests/meetings.edge.test.ts` |

- `docs/requirements.md`의 해당 R-xx 규칙, M2-Q1~Q9, "팀원이 스스로 정한 부분"(확정됨) 중 **기존 테스트가 다루지 않는 경우**를 찾아 테스트를 추가합니다
- **`src/` 는 수정하지 않습니다.** 테스트가 요구사항과 다른 동작(버그)을 발견하면 그 테스트는 넣지 말고 코디네이터에게 보고합니다
  (테스트를 skip 처리하지 않습니다 — guards가 막습니다)

## 진행 방식
1. 리드는 위 배정 그대로 진행한다는 **한 줄 계획**을 사람에게 보고하고 승인을 기다린다
2. 승인되면 에이전트 팀으로 팀원 3명을 띄운다. spawn 프롬프트에 반드시 포함:
   - 맡은 모듈과 만들 파일, worktree·브랜치 이름(`agent/<팀원 이름>`)
   - **`AGENTS.md` "팀 작업"의 명령 형식 표에 있는 명령만 사용할 것. `cd`와 `&&` 연결 금지.**
     표에 없는 명령이 필요하면 실행하지 말고 리드에게 먼저 메시지
3. 팀원 PR 3개가 올라오면 통합 점검(합쳐서 충돌 없음, `npm run check` 통과)
4. 팀원 종료 후 `/verify` 형식으로 보고

## 완료 조건
1. PR 3개, 각각 CI 통과, 각 PR은 배정된 테스트 파일 1개만 추가
2. 합친 상태에서 충돌 없음, `npm run check` 통과
3. 리드는 `src/`, `tests/` 를 직접 수정하지 않음
